# CL018: Unknown field that Concourse ignores

**Severity:** warning

## What is checked?

Unknown fields that Concourse silently ignores: at the top level, in resources, resource types, jobs, groups, var sources and below a task `config`. Such a typo (`sorce:`) is almost always a bug. Keys inside free-form blocks are not checked, and a top-level key that only holds anchors is fine.

## Example

```yaml
resources:
- name: repo
  type: git
  sorce: {uri: https://github.com/example/app.git}   # CL018: did you mean "source"?
```

## Fix

Correct the field name, or remove it.

## Suppress

```yaml
# concourse-lint:ignore CL018 -- reason
```

See [suppression](../../spec/README.md#suppression).
