# CL024: Content after the first YAML document

**Severity:** warning

## What is checked?

A `---` or `...` line after the pipeline with more content behind it. Concourse reads only the first YAML document of a file and ignores the rest without a word, also when it is broken YAML. concourse-lint does the same: it checks only the first document and reports this line once. A `---` before the pipeline (after comments) and a `---` with only comments after it are fine.

## Example

```yaml
jobs:
- name: test
  plan:
  - get: repo
---                 # CL024: the job below is ignored
jobs:
- name: deploy
```

## Fix

Move the second document into a file of its own (a second pipeline is set with its own `fly set-pipeline`). If it belongs to the pipeline, remove the `---` line.

## Suppress

```yaml
--- # concourse-lint:ignore CL024 -- reason
```

See [suppression](../../spec/README.md#suppression).
