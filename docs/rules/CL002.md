# CL002: get/put or a group refers to a missing resource

**Severity:** error

## What is checked?

Every `get:` and `put:` step needs a resource under `resources:`. If `resource:` is set, only that value counts; the name after `get:`/`put:` is then just the artifact name.

Every entry under `groups[].resources` must also name a resource. These entries are exact names, not globs (unlike `groups[].jobs`).

## Example

```yaml
resources:
- name: repo
  type: git
  source: {uri: https://github.com/example/app.git}

jobs:
- name: build
  plan:
  - get: rep      # CL002: resource "rep" is not defined, did you mean "repo"?
```

## Fix

Correct the name or add the resource under `resources:`.

## Suppress

```yaml
# concourse-lint:ignore CL002 -- reason
```

See [suppression](../../spec/README.md#suppression).
