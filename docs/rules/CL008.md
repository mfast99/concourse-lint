# CL008: ((.:var)) without load_var

**Severity:** error

## What is checked?

`((.:name))` needs a `load_var: name` earlier in the same job, or an `across` variable of the step it is in. `((.:name.field))` refers to `name`. A name with a dot is quoted: `((.:"local.var"))` refers to `load_var: local.var`. A `load_var` with `across` defines its variable only inside that step.

## Example

```yaml
  - load_var: version
    file: repo/version
  - task: deploy
    file: repo/ci/deploy.yml
    params:
      VERSION: ((.:verison))   # CL008: did you mean "version"?
```

## Fix

Add the `load_var` before the step, or correct the name.

