# CL004: Resource type is not defined

**Severity:** error

## What is checked?

The `type` of a resource, a resource type and an inline task's `image_resource` must be a built-in type (bosh-io-release, bosh-io-stemcell, cf, docker-image, git, github-release, hg, mock, pool, registry-image, s3, semver, time, tracker) or a type defined under `resource_types:`. Type names are case-sensitive.

## Example

```yaml
resources:
- name: repo
  type: gti        # CL004: did you mean "git"?
  source: {uri: https://github.com/example/app.git}
```

## Fix

Correct the type, or define it under `resource_types:`.

