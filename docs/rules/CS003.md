# CS003: TLS verification disabled

**Severity:** warning

## What is checked?

TLS verification switched off: a true `skip_ssl_verification`, `insecure` or `disable_ssl`, or a non-empty `insecure_registries`, in the `source` of resources, resource types and `image_resource`, and in `get_params` of a put.

## Example

```yaml
resources:
- name: repo
  type: git
  source:
    uri: https://git.internal/app.git
    skip_ssl_verification: true   # CS003
```

## Fix

Trust the certificate instead (e.g. `ca_cert`/`ca_certs`).

## Suppress

```yaml
# concourse-lint:ignore CS003 -- reason
```

See [suppression](../../spec/README.md#suppression).
