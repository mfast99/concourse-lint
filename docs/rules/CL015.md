# CL015: Invalid suppression comment

**Severity:** warning

## What is checked?

A suppression comment needs at least one rule ID, and every ID must exist (case-sensitive). An unknown ID suppresses nothing; the valid IDs of the same list still apply. CL015 itself cannot be suppressed.

## Example

```yaml
  - task: image
    # concourse-lint:ignore CS060   # CL015: did you mean "CS006"?
    privileged: true
```

## Fix

Correct the rule ID. Syntax: `# concourse-lint:ignore CS006,CS001 -- reason`.

## Suppress

CL015 cannot be suppressed.
