# CL013: Cycle via passed:

**Severity:** error

## What is checked?

The jobs connected by `passed:` must not form a cycle (across all resources); jobs in a cycle never run. Every `passed:` entry that is part of a cycle is reported, also a job that waits for itself.

## Example

```yaml
jobs:
- name: a
  plan: [{get: repo, passed: [b]}]   # CL013
- name: b
  plan: [{get: repo, passed: [a]}]   # CL013
```

## Fix

Remove one `passed:` entry of the cycle.

