# CL011: Task input without an available artifact

**Severity:** error

## What is checked?

Every input of an inline task must be an artifact that is available at this point (see CL007 for what is available). Inputs with `optional: true` and inputs provided by `input_mapping` (checked by CL012) are skipped. Tasks from `file:` are not checked, because their inputs are unknown.

## Example

```yaml
  - get: repo
  - task: compile
    config:
      platform: linux
      inputs:
      - name: repo
      - name: cache      # CL011: input "cache" is not available at this point
      run: {path: repo/ci/compile.sh}
```

## Fix

Fetch or produce the artifact in an earlier step, mark the input `optional: true`, or map it with `input_mapping`.

If a `get` or `put` earlier in the job has a misspelled resource (CL002), its artifact is missing too. The hint then points to that step: fixing it there fixes both findings.

## Suppress

```yaml
# concourse-lint:ignore CL011 -- reason
```
