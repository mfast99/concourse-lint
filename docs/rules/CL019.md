# CL019: Value fails when the step runs

**Severity:** error

## What is checked?

Values that fly accepts but that fail every time the step or check runs: `timeout` (any step) and `check_timeout` (resources) must be Go durations (`10m`, `1h30m`), load_var `format` one of `json`, `yaml`, `yml`, `raw`, `trim`.

## Example

```yaml
  - task: unit
    file: repo/ci/unit.yml
    timeout: 1d      # CL019: no days in Go durations, use 24h
```

## Fix

Use a valid value.

## Suppress

```yaml
# concourse-lint:ignore CL019 -- reason
```

See [suppression](../../spec/README.md#suppression).
