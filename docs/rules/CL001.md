# CL001: Structural error

**Severity:** error

## What is checked?

The structure that Concourse requires: no unknown fields in steps, inline task `config` and `across`; the right type for every field; required fields (e.g. a task needs `file:` or `config:`); exactly one step kind per step; at least one job; values with a fixed format such as `check_every`. fly rejects all of these.

## Example

```yaml
jobs:
- name: test
  plan:
  - get: repo
    trigger: yes
    passed: unit     # CL001: passed: must be a list
```

## Fix

Correct the field as the message says. The hint names the expected type or a close field name.

## Suppress

```yaml
# concourse-lint:ignore CL001 -- reason
```
