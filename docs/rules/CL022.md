# CL022: Template instead of a pipeline

**Severity:** info

## What is checked?

Whether the file is a [ytt](https://carvel.dev/ytt/), [spruce](https://github.com/geofffranks/spruce), ERB or Jinja template instead of a pipeline. Before it is rendered, a template is no pipeline: values come from `#@` comments or `(( ... ))` operators, so the other rules would report false positives. A template gets only this one finding, at its first marker, and is not checked otherwise. In a folder, templates are skipped like task files.

* **ytt:** a comment that starts with `#@` (`#@ load(...)`, `#@ for ...`, `key: #@ value`, `#@overlay/match ...`). `# @todo` or a `#@` inside a string is no marker.
* **spruce:** a value that is a whole spruce operator call with a space inside, e.g. `(( grab meta.repo ))` or `(( append ))`. Concourse variables never have a space inside the parentheses, so `((grab))` is a variable, not spruce.
* **ERB and Jinja:** a tag `<% %>`, `<%= %>`, `{% %}` or `{# #}` outside comments and block scalars (scripts), or a line that starts with `<%`, `%>` or `{%`. `{{ … }}` alone is no marker, because it is also the old Concourse variable syntax.

## Example

```yaml
resources:
- name: repo
  type: git
  source:
    uri: (( grab meta.repo ))   # CL022: spruce template
```

## Fix

Check the rendered pipeline instead of the template:

```sh
ytt -f pipeline.yml -f values.yml | concourse-lint check -
spruce merge base.yml prod.yml | concourse-lint check -
```

If the template is close enough to a pipeline to be checked as it is, switch CL022 off in `.concourse-lint.yml` (`CL022: off`) or suppress it for the file: the file is then checked like a pipeline, also in a folder. To skip templates silently, use `exclude` in the config file.

## Suppress

```yaml
# concourse-lint:ignore-file CL022 -- reason
```

A suppressed CL022 works like `CL022: off`: the template is checked like a pipeline. See [suppression](../../spec/README.md#suppression).
