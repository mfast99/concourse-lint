# CB002: check_every below one minute

**Severity:** warning

## What is checked?

A `check_every` below one minute on a resource or resource type puts load on the external system (and on Concourse). `1m` and more, and `never`, are fine.

## Example

```yaml
resources:
- name: repo
  type: git
  check_every: 10s     # CB002
  source: {uri: https://github.com/example/app.git}
```

## Fix

Use `1m` or more, or a webhook (`webhook_token`).

## Suppress

```yaml
# concourse-lint:ignore CB002 -- reason
```

See [suppression](../../spec/README.md#suppression).
