# CS007: Privileged resource type

**Severity:** warning

## What is checked?

A resource type with `privileged: true` runs its containers with full root access to the worker.

## Example

```yaml
resource_types:
- name: dind
  type: registry-image
  privileged: true     # CS007
  source: {repository: example/dind-resource, tag: "2.0.0"}
```

## Fix

Remove `privileged:` unless the resource really needs it.

## Suppress

```yaml
# concourse-lint:ignore CS007 -- reason
```

See [suppression](../../spec/README.md#suppression).
