# CL006: Resource is never used

**Severity:** error

## What is checked?

Every resource must be used by a `get` or `put` (also via `resource:`) somewhere in a job, hooks included. Concourse rejects the pipeline otherwise. A name at the start of a `file:` path is no use.

## Example

```yaml
resources:
- name: repo
  type: git
  source: {uri: https://github.com/example/app.git}
- name: old-repo   # CL006: resource "old-repo" is never used
  type: git
  source: {uri: https://github.com/example/old.git}
```

## Fix

Use the resource in a job, or remove it.

## Suppress

```yaml
# concourse-lint:ignore CL006 -- reason
```

See [suppression](../../spec/README.md#suppression).
