# CB003: Job without steps

**Severity:** warning

## What is checked?

A job whose `plan` is missing or empty does nothing. Concourse accepts it; usually the plan was forgotten or the job is a leftover.

## Example

```yaml
jobs:
- name: deploy       # CB003
  plan: []
```

## Fix

Add steps, or remove the job.

## Suppress

```yaml
# concourse-lint:ignore CB003 -- reason
```

See [suppression](../../spec/README.md#suppression).
