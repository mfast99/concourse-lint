# CB001: Resource type is not used

**Severity:** info

## What is checked?

A resource type that nothing refers to: no resource, no other resource type and no `image_resource`. In a chain of unused types only the end is reported. An override of a built-in type is used when resources of that type exist.

## Example

```yaml
resource_types:
- name: slack          # CB001
  type: registry-image
  source: {repository: cfcommunity/slack-notification-resource, tag: "1.7.0"}
```

## Fix

Remove the type, or use it.

## Suppress

```yaml
# concourse-lint:ignore CB001 -- reason
```

See [suppression](../../spec/README.md#suppression).
