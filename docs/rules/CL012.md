# CL012: input_mapping/output_mapping points to nothing

**Severity:** error

## What is checked?

An `input_mapping` value must be an artifact available at this point (the artifact name, not the resource name). An `output_mapping` key must be an output of the inline task; for tasks from `file:` the outputs are unknown and not checked.

## Example

```yaml
  - get: repo
  - task: unit
    file: repo/ci/unit.yml
    input_mapping:
      source: rpo      # CL012: did you mean "repo"?
```

## Fix

Correct the name.

If a `get` or `put` earlier in the job has a misspelled resource (CL002), its artifact is missing too. The hint then points to that step: fixing it there fixes both findings.

