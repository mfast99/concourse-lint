# CS006: Privileged task

**Severity:** warning

## What is checked?

A task step with `privileged: true` runs with full root access to the worker.

## Example

```yaml
  - task: build-image
    privileged: true     # CS006
    file: repo/ci/build.yml
```

## Fix

Remove `privileged:` unless the task really needs it (e.g. building images); then suppress the finding with a reason.

## Suppress

```yaml
# concourse-lint:ignore CS006 -- reason
```

See [suppression](../../spec/README.md#suppression).
