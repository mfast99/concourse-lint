# CL021: String contains a literal tab

**Severity:** info

## What is checked?

A literal tab character inside a plain, single-quoted or double-quoted string. YAML and Concourse accept it and keep the tab, but it is almost never meant: it usually comes from pasting out of a terminal or an editor that inserts tabs. Tabs in block scalars (`|`, `>`) are not reported, because they are normal in scripts and heredocs. Tabs around a value (before a comment, at the end of a line) are whitespace and not reported either.

## Example

```yaml
    params:
      MESSAGE: "build	done"   # CL021: the gap is a tab, not spaces
```

## Fix

Replace the tab with spaces. If the tab is intended, write it as the escape `\t` in double quotes: `MESSAGE: "build\tdone"`. That is no finding.

## Suppress

```yaml
# concourse-lint:ignore CL021 -- reason
```
