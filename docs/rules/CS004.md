# CS004: Unencrypted URL

**Severity:** warning

## What is checked?

A value in a `source` that starts with `http://` or `git://`, also nested. `localhost`, `127.0.0.1` and `[::1]` are exempt, but only as the whole host name.

## Example

```yaml
resources:
- name: repo
  type: git
  source:
    uri: http://git.internal/app.git   # CS004
```

## Fix

Use `https://` or SSH.

## Suppress

```yaml
# concourse-lint:ignore CS004 -- reason
```

See [suppression](../../spec/README.md#suppression).
