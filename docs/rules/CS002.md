# CS002: Known token format found

**Severity:** error

## What is checked?

Known token formats anywhere in the file, also in comments: AWS access key IDs, GitHub and GitLab personal access tokens, Slack webhooks and bot tokens, Stripe live keys, PEM and OpenSSH private keys (not a frame around a placeholder or a `((var))`). It replaces CS001 at the same place.

## Example

```yaml
    params:
      GITHUB_TOKEN: ghp_0123456789abcdefghijklmnopqrstuvwxyz   # CS002
```

## Fix

Remove the token from the file, revoke it, and use a `((var))` from a credential manager.

## Suppress

```yaml

```
