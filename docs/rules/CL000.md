# CL000: YAML syntax error

**Severity:** error

## What is checked?

The file must be valid YAML. A broken file gives exactly one CL000 and nothing else, because nothing else can be checked. Broken aliases and alias bombs count as syntax errors too, because fly rejects the whole file.

CL000 cannot be suppressed or switched off.

## Example

```yaml
jobs:
- name: test
  plan: [{get: repo}     # CL000: the flow list is never closed
```

## Fix

Fix the YAML syntax at the reported position.

## Suppress

CL000 cannot be suppressed.
