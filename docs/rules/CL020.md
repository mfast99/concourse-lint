# CL020: Unknown keyword that Concourse ignores

**Severity:** warning

## What is checked?

Words that Concourse silently ignores: `version` of a get knows only `latest` and `every` (or a mapping), `inputs` of a put only `all` and `detect` (or a list). Any other word falls back to the default.

## Example

```yaml
  - get: repo
    version: evry     # CL020: did you mean "every"?
```

## Fix

Correct the word.

## Suppress

```yaml
# concourse-lint:ignore CL020 -- reason
```

See [suppression](../../spec/README.md#suppression).
