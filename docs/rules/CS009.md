# CS009: load_var reveals the value in the log

**Severity:** info

## What is checked?

A `load_var` with `reveal: true` shows the loaded value in the build log.

## Example

```yaml
  - load_var: version
    file: repo/version
    reveal: true         # CS009
```

## Fix

Remove `reveal:` if the value can be secret.

## Suppress

```yaml
# concourse-lint:ignore CS009 -- reason
```

See [suppression](../../spec/README.md#suppression).
