# CS008: Public build logs

**Severity:** warning

## What is checked?

A job with `public: true` shows its build logs to everyone who can see the pipeline, also without logging in.

## Example

```yaml
jobs:
- name: deploy
  public: true         # CS008
  plan: [{get: repo}]
```

## Fix

Make sure the logs contain no secrets, or remove `public:`.

## Suppress

```yaml
# concourse-lint:ignore CS008 -- reason
```

See [suppression](../../spec/README.md#suppression).
