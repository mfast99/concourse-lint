# CL009: Job in passed: does not use the resource

**Severity:** error

## What is checked?

A job in `passed:` must itself get or put the same resource (also via `resource:`). Concourse rejects the pipeline otherwise. The artifact name does not matter.

## Example

```yaml
jobs:
- name: unit
  plan: [{get: repo}]
- name: deploy
  plan:
  - get: image
    passed: [unit]   # CL009: job "unit" does not use resource "image"
```

## Fix

Remove the job from `passed:`, or name a job that uses the resource.

## Suppress

```yaml
# concourse-lint:ignore CL009 -- reason
```

See [suppression](../../spec/README.md#suppression).
