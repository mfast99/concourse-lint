# CL016: Job in no group

**Severity:** error

## What is checked?

When the pipeline has groups, every job must be in at least one group (by name or glob). Concourse rejects the pipeline otherwise.

## Example

```yaml
groups:
- name: ci
  jobs: [test]

jobs:
- name: test
  plan: [{get: repo}]
- name: deploy    # CL016: job "deploy" belongs to no group
  plan: [{get: repo}]
```

## Fix

Add the job to a group, or use a glob.

## Suppress

```yaml
# concourse-lint:ignore CL016 -- reason
```

See [suppression](../../spec/README.md#suppression).
