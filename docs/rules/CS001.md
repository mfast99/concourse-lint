# CS001: Plaintext secret

**Severity:** warning

## What is checked?

A secret-like key with a fixed value: the last word of the key (split at `_`, `-` and case changes) is `password`, `passwd`, `secret` or `token`, or the last two are `private`, `api`, `access` or `secret` plus `key`. Checked in `source`, task `params`, `set_pipeline` `vars` and the `config` of `var_sources`. A value that is only a `((var))`, an empty value, booleans, numbers, `x-oauth-basic` (GitHub's fixed password for token auth) and placeholders (`REDACTED`, `<…>`, `YOUR-…`, `REPLACE-…`) are fine.

## Example

```yaml
resources:
- name: api
  type: mock
  source:
    password: hunter2     # CS001
```

## Fix

Store the value in a credential manager and use a `((var))`.

## Suppress

```yaml
# concourse-lint:ignore CS001 -- reason
```
