# CS005: Image without a fixed tag or digest

**Severity:** warning

## What is checked?

An image in `image_resource` or `resource_types` of type `registry-image` or `docker-image` without a fixed tag or digest, or with the tag `latest`. A `((var))` tag and `version: {digest: ...}` count as pinned. Regular resources track new versions on purpose and are not checked.

## Example

```yaml
resource_types:
- name: slack
  type: registry-image
  source:
    repository: cfcommunity/slack-notification-resource   # CS005
```

## Fix

Add a fixed tag (`tag: "1.7.0"`) or a digest.

## Suppress

```yaml
# concourse-lint:ignore CS005 -- reason
```

See [suppression](../../spec/README.md#suppression).
