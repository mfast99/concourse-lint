# CL003: passed: names a missing job

**Severity:** error

## What is checked?

Every entry of `passed:` must name an existing job. Job names are case-sensitive.

## Example

```yaml
jobs:
- name: unit
  plan: [{get: repo, trigger: true}]
- name: deploy
  plan:
  - get: repo
    passed: [unti]   # CL003: did you mean "unit"?
```

## Fix

Correct the job name.

## Suppress

```yaml
# concourse-lint:ignore CL003 -- reason
```

See [suppression](../../spec/README.md#suppression).
