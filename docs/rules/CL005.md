# CL005: Duplicate name

**Severity:** error

## What is checked?

Names must be unique within a category: resources, resource types, prototypes, var sources, jobs and groups, and within a job the names of `get` steps and of `load_var` steps. fly rejects all of these. Every further occurrence is reported. Repeated `task`, `put` and `set_pipeline` names are allowed.

## Example

```yaml
resources:
- name: repo
  type: git
  source: {uri: https://github.com/example/app.git}
- name: repo     # CL005: resource "repo" is defined more than once
  type: git
  source: {uri: https://github.com/example/other.git}
```

## Fix

Rename or remove the duplicate.

## Suppress

```yaml
# concourse-lint:ignore CL005 -- reason
```
