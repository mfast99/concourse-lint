# CL017: Unquoted value changes when Concourse reads it

**Severity:** warning

## What is checked?

Concourse reads YAML 1.1. An unquoted value that YAML 1.1 reads as a number reaches the resource or task in the spelling of that number: `1.10` becomes `1.1`, `0022` becomes `18`. This is reported in free-form blocks (`source`, `params`, `vars`, `across` values) and in string fields outside steps (`name: yes` becomes "true").

## Example

```yaml
resource_types:
- name: slack
  type: registry-image
  source:
    repository: cfcommunity/slack-notification-resource
    tag: 1.10       # CL017: unquoted 1.10 is passed on as 1.1
```

## Fix

Quote the value: `tag: "1.10"`.

## Suppress

```yaml
# concourse-lint:ignore CL017 -- reason
```

See [suppression](../../spec/README.md#suppression).
