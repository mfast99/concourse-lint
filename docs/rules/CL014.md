# CL014: Task output shadows an artifact

**Severity:** warning

## What is checked?

An output of an inline task (or its `output_mapping` target) with the name of an artifact that is already available silently replaces that artifact for the following steps. It is fine when the same name is also an input of the task ("modify in place").

## Example

```yaml
  - get: repo
  - get: version
  - task: bump
    config:
      inputs: [{name: repo}]
      outputs: [{name: version}]   # CL014: replaces the artifact "version"
```

## Fix

Rename the output, or add it as an input to modify it in place.

## Suppress

```yaml
# concourse-lint:ignore CL014 -- reason
```

See [suppression](../../spec/README.md#suppression).
